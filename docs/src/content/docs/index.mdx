## What kawasekit is

kawasekit is a TypeScript SDK that gives AI agents a wallet that disappears.
Developers integrate the SDK; agents pay per-call in stablecoins (JPYC, USDC);
end users never see gas, mnemonics, or chains.

Built for the Japanese stablecoin landscape first — JPYC is the primary
target — but the architecture is chain-agnostic and the same primitives work
for any EIP-3009 + ERC-4337 token.
