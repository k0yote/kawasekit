## kawasekit とは

kawasekit は AI エージェントに「消えていく財布」を提供する TypeScript SDK
です。開発者が SDK を組み込み、エージェントは呼び出しごとに JPYC や USDC
で支払い、エンドユーザーはガス代やニーモニック、チェーンの存在を意識する
必要がありません。

日本のステーブルコインエコシステム (特に JPYC) を最初のターゲットとして
います。アーキテクチャはチェーン非依存で、EIP-3009 + ERC-4337
対応のトークンであれば同じ仕組みが使えます。

## ステータス

M4 完了 — `kawasekit@0.1.0-beta.2` を npm に公開済み
(`pnpm add kawasekit@beta`、SLSA provenance 付き) で mainnet 対応ですが、
**GA ではありません**。reasoning-step idempotency gap (THREAT_MODEL §6.1) が
閉じるまで本番利用は小額の per-call value に制約され、GA (`0.1.0` / `latest`
タグ) は M5 予定です。最新の進捗は
[GitHub プロジェクト](https://github.com/k0yote/kawasekit) を、
脆弱性の報告は[セキュリティポリシー](/ja/reference/security/) を
参照してください。
